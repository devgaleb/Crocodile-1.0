# Sersgi Pizza Italian — Funny Edition 🍕🤌

A playful Italian-pizza restaurant landing page with meme-style jokes, a menu, reviews, contact details, and a reservation demo form.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.

The exact brand spelling is **Sersgi Pizza Italian**. Some images and fonts load from online services. The contact details are demo placeholders and the reservation form does not submit to a real booking system.
